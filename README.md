# Customer Analysis Dashboard Using Excel

## Project Overview

The Customer Analysis Dashboard project focuses on analysing customer data to understand customer behaviour, sales performance, revenue generation, and business trends.

An interactive dashboard was developed using Microsoft Excel to visualize important business metrics and provide meaningful insights for better decision-making.

## Project Objectives

- Analyse overall customer performance.
- Understand customer purchasing behaviour.
- Identify revenue trends.
- Analyse customer segments.
- Evaluate region-wise sales performance.
- Identify top-performing products and services.
- Monitor important business KPIs.

## Tools & Technologies

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Slicers
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset Description

The dataset contains customer-related information, including customer details, sales transactions, revenue, product categories, regions, and purchasing information.

## Key Performance Indicators (KPIs)

- Total Revenue
- Total Customers
- Total Orders
- Average Order Value
- Total Sales
- Customer Segments

## Dashboard Features

- Overall Customer Analysis
- Revenue Analysis
- Region-wise Sales Analysis
- Product-wise Performance
- Customer Segmentation
- Sales Trend Analysis
- Interactive Slicers and Filters

## Key Insights

- Analysed overall customer and sales performance.
- Identified important customer segments.
- Evaluated revenue trends.
- Compared regional sales performance.
- Identified top-performing products and categories.
